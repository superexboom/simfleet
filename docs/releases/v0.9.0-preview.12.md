GPU 吞吐优化本地测试版，使用同版 CPU PGO 引擎与可选 NVIDIA `sfg2` 套件。

- GPU 从已经领取的有界候选窗口中选取能够组成最大批量的同类场景，避免最早的小队列挡住后面的完整批次。CPU 收尾保留更多任务，减少 GPU 尾批拖延整体完成的问题。
- 私有页新增 256/512 KiB 档位。GPU 基础内存预留参考 worker 启动后的实际提交量，加保守余量；原来的 CPU＋GPU 总提交硬上限、显存余量限制、私有页总容量限制继续生效。
- `sfg2` 套件在保留精度、随机序列、模拟次数及计分的前提下，使用对齐整字读写，并限制每线程寄存器数量。客户端优先选择匹配架构的 `sfg2`，同时兼容现有 `sfg1`。
- 批次日志新增准备、GPU 计算、下载、合并耗时，便于用有效工作量与时间判断吞吐。
- GPU 桥接编译产物按源哈希缓存；八个探测样本使用独立执行组。探测时间上限为 12 秒，进入完整计算的收益门槛仍为 6 秒；无收益场景逐步延长重评间隔。
- 完整任务或探测超时只暂缓相应场景，15 秒后恢复其他 GPU 工作；初始化与驱动故障继续使用原来的递增退避，不再因慢任务把整个设备罚等数分钟。

验证数据和适用范围见 [GPU 吞吐优化](../gpu-throughput.md)。sm120 在本机 RTX 5080 上实测；sm75/sm89 为交叉编译包，不代表已在目标显卡上验证速度。CPU DLL、GPU 套件和客户端仍分别打包。
