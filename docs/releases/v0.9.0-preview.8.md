包含 preview.7 的 NVIDIA 自动学习、按 GPU 计算能力选择套件、显存限额、GPU 贡献速度显示及 Windows PGO v3 引擎支持。现有 sm75 / sm89 / sm120 套件分别覆盖 GTX 16 / RTX 20、RTX 40、RTX 50 系列，无需按具体显卡型号下载不同客户端。

修复发布前强制故障回放发现的暂缓计数问题：同一批八行属于同一场景时，一次 worker 故障曾记为八次失败，把首次暂缓从 30 分钟放大到 4 小时。现在每次失败按场景去重，首次 30 分钟，到期重评；完整批次资源回退也使用同样规则。策略绑定升级，避免继续使用旧版过长的暂缓记录。

贡献总速度已包含 CPU＋GPU 正常完成工作，“其中GPU”显示同一十分钟窗口里的 GPU 部分；探测不计成绩，故障回到 CPU 后也不会重复计入 GPU。Windows 使用独立发布的 sfe2 PGO v3 DLL；NVIDIA 套件[单独发布](https://github.com/superexboom/simfleet/releases/tag/gpu-4296a0964da6-sfg1)。sm75、sm89 为待目标架构实机验收的交叉编译测试包；sm120 已在该架构设备上通过完整结果对照，未逐型号覆盖。

客户端包保持程序、README 和三份许可/署名文件，不附带引擎 DLL、GPU 包、诊断日志或测试材料。
