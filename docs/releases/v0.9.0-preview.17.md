新增 **S → 每路线程上限**（`slot_threads`）：默认 0 保持共享线程池，正数按物理核与 SMT 成组分配每路 CPU 线程，避免一条榜单任务占满整台多核机器。

- 每路标题显示已用/可用线程。按 NUMA/末级缓存划分，同核 SMT 优先成组；奇数额度和 Intel P/E 核混合分配保留剩余逻辑线程。
- 自动模式启动时直接打开覆盖当前线程预算所需的路数，服从并发上限；更多路数轮流共享分区，每路仍不超过配置额度。
- 协议 8 提前预取结合剩余模拟进度与网络耗时；启用分组后通常提前到半包剩余量，仍遵守服务器领取间隔和持包上限。
- 自动并发判断周期缩短至 5 秒，任务信号与错峰等待提前准备。
- 改动保存后排空并自动重启生效。已有 CPU DLL 和匹配的 GPU 套件可继续使用。

用例覆盖了双 CCD、NUMA、奇数额度、P/E 混合、配置和菜单；本机绑核检查与本地服务器联调通过。7 线程、每路上限 3 时，实际三路分配为 3＋3＋1，预取没有提前越过服务端期限。没有新增全量测试或宣称跨机器吞吐收益。

7 线程共享给六路时，六路均完成计算并提交结果，各路未超过额度，未出现提前领取。

9950 系列可从 `slot_threads=8`、允许四路、`placement="cache"` 开始。具体限制、尾部分区和平台差异见[每路线程与预取说明](https://github.com/superexboom/simfleet/blob/main/docs/slot-threads.md)。

升级后默认 `slot_threads=0`，可在 S 菜单中开启。客户端包仍为原有五文件；[CPU 原生引擎](https://github.com/superexboom/simfleet/releases/tag/engine-3194962a0af7)与 [RTX 50 系列 sm120 GPU 套件](https://github.com/superexboom/simfleet/releases/tag/gpu-3194962a0af7-sfg3)独立发布，已有匹配版本无需重新下载。三平台发布检查仅运行本次调度、拓扑和设置的相关用例。
