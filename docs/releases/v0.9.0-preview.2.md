GPU 预览版扩大已验证的榜单场景，并显示实际 GPU 工作状态和本程序的 GPU 资源使用。

- 新增 Zenith / demolisher / base、Torid / demolisher / cycle 分流。保留 Fulmin Prime / heavy_gunner / semi_auto；Torid 多目标继续 CPU。
- 固定总计算量的预热离线对照：Zenith CPU＋GPU 比仅 CPU 吞吐提高 25.8%，Torid 爆破使提高 30.8%。条件为 Ryzen 7 9700X、16 条 CPU 线程、RTX 5080、引擎 `62a82930d1d3`；不能外推到整个实网队列。
- 顶部新增 GPU 状态指示；右侧资源区显示初始化、待机、准备、计算、合并或故障回退，以及当前批次行数、模拟次数、等待秒数、累计完成行数。
- 右侧“程序GPU”使用 Windows WDDM 按本客户端 GPU 子进程 PID 读取的最忙引擎占用，每秒异步采样；另显示独立显存和共享显存。没有有效计数时显示 `--`，不拿整张卡的占用冒充本程序。
- 窄窗口保留简版 GPU 状态和占用。GPU 行使用活动指示，不再以 0% 假装可观测的逐局进度。
- 客户端版本为 `0.9.0-preview.2`。GPU 二进制协议与包仍为 `sfg1`，已有匹配的 GPU 包可继续用，不需要重编译 cubin。

所有 GPU 任务仍保留版本校验、逐行 WASM canary、内存上限、批次超时和 CPU 回退。具体筛选与限制见 `docs/gpu-coverage.md`。
