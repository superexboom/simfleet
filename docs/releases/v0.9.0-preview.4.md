保留 preview.3 的领取调度修复，并修复一次 GPU 私有页超限就永久停用 GPU 的问题。

- GPU `120` 私有页不足和 `2` 输出容量不足按行回退 CPU，同批正确的行正常完成，GPU 继续下一批。
- 后续单局私有页预算从 192 KiB 逐级提升到 384／768 KiB，同时批量上限缩小到 8,000／4,000 次，保持约 3 GiB 的私有页总预算。
- 记住最多 512 个失败请求哈希，避免立即重复失败；worker 退出或超时后最多自动恢复两次，界面显示恢复倒计时。
- 版本、架构、哈希或计算结果不一致仍停用 GPU，不提交部分或错误结果。
- 保留领取间隔倒计时、后台设备绑定、冷却期信号刷新和自动补足空闲组的修复。原有配置和 CPU 计算预算不变。

GPU 引擎二进制包仍使用 `sfg1`，不需要重新下载或编译 DLL/cubin。诊断和验证细节见 `docs/dispatch-and-gpu-recovery.md`。
