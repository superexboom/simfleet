提升 NVIDIA 榜单任务吞吐，并改进测速、界面和 GPU 学习记录保存。支持 sfg3 引擎内存布局，在不改变运行次数、随机序列、gas、精度和评分的前提下，减少每局私有状态占用并扩大 GPU 批量。

- 私有页由 4 KiB 改为 1 KiB，页索引由 32 位改为 16 位。正式套件选择平铺页表；稀疏页表因额外查询成本保留为研究路径。
- 新布局增加 64/96/128/160 KiB 单局配额，探测按实际页大小换算。新包最多 32 行 / 32000 次，实际批量受提交预算、系统余量、显存、私有页池及故障缩批共同限制。
- Windows 默认 CPU＋GPU 总提交上限仍为 8192 MiB，显存另计。旧 GPU 套件维持原布局和批量边界。
- GPU worker 工作缓冲与快照槽位分开，支持超过 16 行的批次；保留逐行 WASM 核对和 CPU 回退。
- sfg3 的完整批次超时随模拟数量在 30–120 秒内增长，避免扩大批量后仍被旧的固定 30 秒时限提前回收。探测仍为 12 秒。
- 从已领取的有界候选窗口中挑选能组成较大批量的同类任务，减少小队列挡住大批次；缓存 GPU 桥接编译产物。任务超时暂缓对应场景，15 秒后恢复其他 GPU 工作。
- CPU 和 GPU 分别按实际工作时间计算速度，等待任务和暂停时停止计时。总速度按两者活跃时间的并集计算，不能把设备速度直接相加；探测和失败工作仍计入时间。
- 顶栏改为两行，移除重复的核心、并发和在线数。按 `D` 或进入 `S → 侧栏显示项目` 勾选可见栏目，设置立即写入 TOML。
- GPU 学习记录同步刷新并保留备份，异常退出后可恢复；启动显示读取的记录数量，保存失败会提示并重试。

固定旧引擎 `5c64c380e5f2`、240 行五种武器混合任务、8 个 CPU 线程的完整客户端对照：129.530 秒降为 111.305 秒，整机吞吐提高约 16.4%，GPU 分账吞吐提高约 42.6%。新版本进程族提交峰值 7.12 GiB，无故障回退，完整评分与总 work 相同。这是固定离线队列的单轮对照，不是所有武器或所有 GPU 的收益承诺。
