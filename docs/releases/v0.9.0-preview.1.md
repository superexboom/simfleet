本版增加可选 NVIDIA GPU 榜单计算，标记为预览版；常规 CPU 客户端仍保持三个平台和原来的五文件压缩包。

- 在设置菜单中打开 `NVIDIA GPU 预览`，或退出后在 `simfleet.toml` 设置 `gpu_enabled = true`。
- GPU 引擎独立下载、解压到客户端目录，路径是 `engines/gpu/<engine>-sfg1-sm120/`。首次预览支持 Windows x64-v3 CPU 和 `sm_120` NVIDIA GPU，本机验证设备为 RTX 5080。
- 只将已测得收益的 Fulmin Prime / heavy_gunner / semi_auto 榜单批量交给 GPU。CPU 保持并行计算，其他武器、紫卡搜索、小批量和尾部继续使用 CPU。没有匹配包时正常使用 CPU。
- 每批至多 16 条、16,000 次模拟。原请求、随机种子、run 索引、合并顺序、评分和工作计量保持不变；每行的第一局同时与原始 WASM 核对。
- GPU 子进程有 12 GiB 提交上限，计算批次 30 秒超时。异常或校验失败后停用 GPU，任务从头交回 CPU；不提交部分结果。多个 fleet 实例只允许一个占用 GPU 0。
- 暂停、退出、引擎切换会结束 GPU 子进程并释放其资源；旧引擎的 GPU 包不会装入新引擎任务。

GPU 包和 CPU DLL 分别发布，均不放进客户端压缩包。GPU 功能尚未完成数天连续实网运行验证，预览版不会替代 GitHub 的稳定版 Latest。
