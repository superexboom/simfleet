# simfleet 0.9.0 正式版

- 接入上游 `fixed-board-input-v1`：榜单任务携带 `fight` 时原样执行冻结的模拟输入，保留任务的种子、场景、时长和计分项；兼容原有榜单任务和协议 7 回退。
- 跟进上游负射速卡死修复。已经确认有问题的 `c43203504fc4` 不再走原生构建的 48 小时等待窗口，升级后直接检查当前引擎。
- 保留独立的每路领取冷却、根据服务器间隔和网络耗时提前预取、每路线程上限及 SMT/缓存域调度。服务器的 `next_ms` 继续按各路独立遵守。
- 汇总 0.9 预览系列的长期内存恢复、设置实时保存、侧栏显示设置、按活跃时间计速和异常计量隔离等改动。

**升级**：关闭旧客户端后替换程序，保留现有 `simfleet.toml`、`kept/`、`engine-state.json` 和引擎目录。客户端会自动下载匹配的 CPU 引擎。已经卡死的旧引擎线程需随旧进程退出后释放。

**客户端与引擎分别发布**：本页仅含 Windows、Linux、macOS 客户端包，包内仍为原有五个文件。CPU 引擎见对应 `engine-*` Release，Windows 使用 PGO AVX2/v3。本轮不构建 GPU 套件；已有 NVIDIA 功能仍为可选预览，必须匹配当前引擎，缺少套件时由 CPU 计算。
