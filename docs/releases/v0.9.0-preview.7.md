可选 NVIDIA 榜单后端首次公开预览：根据任务上下文自动探测、逐局校验并学习适合 GPU 的场景，CPU 与 GPU 同时计算；探测结果不提交成绩。包含 preview.1–6 已在本机部署的批量调度、临时故障恢复、领取等待诊断和合计内存限制。

- GPU 包按显卡架构自动选择，支持本次提供的 sm75 / sm120 套件。sm120 在 RTX 5080 上验证；sm75 为 GTX 1660 Ti 等 Turing 显卡提供交叉编译测试包，尚未完成该型号实机验收。它们分别发布在 GPU 引擎 Release，不能互换。
- 新增显存参与批量限额计算，小显存卡保留桌面、映射和快照余量。Windows 默认 CPU＋GPU 进程合计提交上限仍为 8 GiB，可在设置中调整；显存另计。
- 贡献速度包含 CPU 与 GPU，新增“其中GPU”显示同一十分钟窗口内 GPU 的贡献和本次累计；修复旧协议单条榜单漏计本机速度。榜单旁每分钟按账号约半小时入账增长估计，口径不同。
- Windows 原生引擎改为一份 x86-64-v3 PGO＋ThinLTO DLL，修订号 sfe2；省去 Windows baseline 构建。需要完整 v3 指令支持，旧 CPU 继续用官方原生或 WASM。Linux 仍保留 baseline/v3，Apple silicon 保留一个原生构建。
- GPU 学习缓存同时绑定原生 DLL 哈希，PGO 更新后重新测速。慢场景探测超时固定 15 秒恢复，不累加其他场景的全局故障退避。
- 修复引擎和客户端发布步骤遇到临时下载/DNS 失败时缺少重试的问题。

客户端包仍只含程序、README 和许可证/署名文件。CPU 引擎、NVIDIA 套件单独发布；不包含编译器、测试数据、诊断日志或技术报告。GPU 为显式开启的预览功能，不保证每种任务都比 CPU 快。
