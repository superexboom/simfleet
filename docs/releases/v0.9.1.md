# simfleet 0.9.1 正式版

- **修复接单卡顿与 `timeout: global` 连续报错**：适配上游主站切换 Cloudflare 代理及香港完整入口（`cn.wfsim.app`）架构；首次请求前并发探测双路延迟选路，连接超时收敛至 10s，榜单同步与提交读取超时上调至 65s 以衔接香港中继 60s 上限，避免百万级队列下慢同步在 30s 被客户端提前中断导致租约孤立与 `early` 拒单；双路同时失败时保留原优先线路并回报真实 HTTP 状态，不再误翻到不可达线路。
- **公开信号、发布元数据与引擎下载双入口容灾**：`/work.json`、`/release.json`、`/pkg/*`（WASM 与数据包）、`/stats/*`、`/api/board/demand` 及 `/api/appraise/*` 均支持主站/CDN 与香港入口自动互备（不跨站携带账号 Cookie）；修正 HTTP `Date` 整秒截断导致的最新快照误判过期问题；侧栏按新格式独立展示全站队列总量与当前可派任务数。
- **紫卡搜索与原生引擎 `sfe3` 加速**：跟进上游 `quickScoreWidth` / `quickScoreSlices` 自适应 gas 均衡切片与 `compact_shards` 紧凑分片传输；接入 `split_finals`（`verify_final` / `finish_finals`）跨全核并行决胜验证（WASM 与 `sfe3` 原生引擎双端支持，旧 `sfe2` 自动兼容回退）；原生榜单合并仅在连续分片实际推进时执行精度检查，并恢复单线程内联优化器标记。

**升级**：关闭旧客户端后替换程序，保留现有 `simfleet.toml`、`kept/`、`engine-state.json` 和引擎目录。客户端优先自动下载匹配的 `sfe3` CPU 原生引擎，未就绪时自动兼容 `sfe2` 或官方 WASM。

**客户端与引擎分别发布**：本页含 Windows、Linux、macOS 客户端包，包内仍为原有五个文件。CPU 引擎见对应 `engine-*` Release（修订号 `sfe3`，Windows 使用 PGO AVX2/v3）。本轮不构建 GPU 套件。
