# v0.9.0-preview.13

修复等待任务和暂停期间速度持续下降的问题。CPU 与 GPU 分别按实际工作时间计算速度，显示“运行 / 计时暂停”；总速度采用两者工作时间的并集，设备速度不直接相加。GPU 探测及失败工作仍消耗其活跃时间。此改动不是吞吐提升。

顶栏改为两行，去掉与侧栏重复的核心、并发和全站在线数。按 `D`，或 `S → 侧栏显示项目`，可用空格或回车勾选显示项目；`R` 恢复默认，`Esc` 返回。更改即时保存到 TOML，不重启计算。

GPU 学习记录同步刷新并保留备份，保存失败明确提示并重试。启动报告已读取记录数；总内存上限变化保留同引擎、同设备的测量。探测启动前持久化未完成状态，避免异常退出后反复撞同一场景。持续成功的场景延长有效期。

GPU 日志补充实际完成 work、探测标记和任务场景，便于计算真实墙钟产出与无效时间。本轮尝试的混合场景调度、独立线程执行组和内存复制内核未取得足够收益，未部署；继续使用现有 `sfg2` 套件，不需重新下载 GPU 引擎。

本地 Windows 包仍只含客户端与四个许可/说明文件。实验记录、性能分析工具及技术文档不混入运行包。

详情见 [GPU 效率与面板说明](../gpu-efficiency-and-dashboard.md)。
