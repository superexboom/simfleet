修复异常 CPU 工作量污染速度与待交统计，并阻塞同批正常答案的问题。

- CPU 榜单结果增加与服务端整数契约相符的 work/计数器检查，异常结果在记分和落盘之前拦截。
- 原生结果计量异常时保存原始输入与输出，整行改用官方 WASM 从零重算一次；合法重算结果才会计分、提交。
- 启动时隔离旧待交文件中的异常行，保留正常答案。隔离结果保存在 `result-diagnostics`，不截断或编造 work。
- 本机实际异常值来自一条 CPU 行：work 约 `2.3036e17`，使本地估算分数变成约 2.3 亿。原生计量最初如何损坏尚未复现，现已增加持久诊断。

此版只更新客户端，沿用 `14c617506965` 对应的 [PGO v3 CPU 引擎](https://github.com/superexboom/simfleet/releases/tag/engine-14c617506965)与 [RTX 50 系列 sm120 GPU 套件](https://github.com/superexboom/simfleet/releases/tag/gpu-14c617506965-sfg3)，已有匹配引擎无需重新下载。客户端包保持原有五文件结构。

验证：两个直接相关的既有用例通过。本机部署后成功隔离一条异常记录，同一路的 399 条正常答案已被服务器接收；配置保持。此次修复不宣称已复现或解决原生计量最初损坏的底层原因。详见[诊断与恢复记录](https://github.com/superexboom/simfleet/blob/v0.9.0-preview.20/docs/work-counter-recovery.md)。
