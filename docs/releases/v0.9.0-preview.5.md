改进长时间运行后的 GPU 恢复、故障诊断和内存预算。

- 临时故障不再耗尽整次运行仅两次的重试机会。按 15／60／300／600 秒退避，之后至多每十分钟恢复一次；至少八个成功批次且健康运行满一分钟后重置退避。版本、哈希、未知状态、协议及结果校验错误仍停用等待检查。
- GPU 状态明确区分无合适任务、CPU 收尾、批量不足、系统内存紧张、恢复倒计时和错误停用，右侧保留上次错误。
- GPU 失败写入轮换调度日志，并保存最多两份 `gpu-diagnostics/*-failure.json`，包含阶段、错误、退出状态及原计算请求，不包含账号和凭据。避免大量完成日志覆盖唯一故障信息。
- 新增 `compute_memory_limit_mb = 8192`。Windows 对 CPU 主进程及 GPU 子进程合计提交实施硬上限；预留 64 MiB 给守护进程。设置菜单“CPU+GPU上限 MiB”可改为 4096～65536，保存后排空任务并自动重启生效。
- GPU 单局私有页预算允许升到 1.5 MiB，对应批量最多 2,000 次；私有页总缓冲仍约 3 GiB。主进程原有 2 GiB 软回收线保留，显存单独显示。

GPU 引擎仍为同引擎的 `sfg1` 包。这些修改不改变战斗规则、随机流、评分或工作计量。
