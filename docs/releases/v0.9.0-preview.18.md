改进 GPU 单局私有页不足（状态 120）的学习与诊断。该状态表示某局模拟超过自己的私有页配额，不等于 CPU+GPU 总提交上限或显存已用满。

- 完整成功行回报全部模拟的私有页峰值，后续按峰值加余量调整额度，不再只依赖 8 局探测。
- sfg3 探测与完整行预留至少 16 KiB 或峰值的 25%，按现有配额档位向上取整；资源不足后提高的额度下限继续保留。
- 同一场景的混合成功/失败批次先处理资源失败。成功行不再把该批次的扩容记录覆盖成性能暂缓，也不再清空同批的失败历史。
- 区分“额度已提高但场景仍暂缓”和“单局已达最高额度”。日志显示实际的旧/新 KiB 配额；dispatch.log 同时记录完整行峰值和各场景调整结果。

保留 CPU+GPU 总提交上限、显存限制、单局最高配额和自动缩批。此版更新客户端即可，同一 engine ID 的 CPU DLL 与 sfg3 GPU 套件继续使用。

验证：两个直接相关的既有用例通过。使用本机记录的真实榜单输入，在 32768 MiB 总限额下受控降低单局配额到 64 KiB，触发状态 120；同一 worker 提高到 128 KiB 后完成全部 1000 次，实测峰值 100 KiB，完整评分与 CPU 参考一致。原记录在新 worker 的原始 128 KiB 配额下未自然复现；这项验证说明额度恢复契约，不代表已复现另一台 5090 的长期状态或消除所有状态 120。
